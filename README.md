# 知识付费系统源码 支持H5、小程序和pc端分站分销多种变现模式

源码获取：ym7k.com/19803/

## ✅ 核心亮点

重点特色：**多分站独立运营 + 二级分销裂变**，分站拥有独立域名、独立首页装修、独立课程，主站统一管控，适合招商加盟、渠道代理模式。

## 📦 内容交付模块

1. **录播视频课程**：章节管理、免费试看、倍速播放、水印防录屏、学习进度跨端同步、断点续学
2. **音频专栏**：有声课、播客，后台持续播放，适合通勤学习
3. **图文专栏 / 付费阅读**：连载文章、付费解锁全文、图集、资料文档
4. **电子书 / 资料下载**：PDF 等资料，购买后下载，可设置下载权限
5. **直播课程（高级版）**：直播授课、回放、弹幕、直播预约提醒

## 💰 多种变现模式（核心）

- 单品购买：单节课程、专栏单独定价购买
- VIP 会员订阅：月卡 / 季卡 / 年卡 / 终身会员，会员免费看指定课程、购课折扣
- 专栏打包套餐：系列课程打包优惠售卖
- 卡密兑换：激活卡、礼品卡，线下引流、企业采购发放
- 优惠券、限时秒杀、拼团、限时免费活动
- 付费问答、付费社群（部分版本包含）

## 🤝 分站代理模块（这套区别于普通网校的重点）

- 主站创建多个分站，**分站独立域名、独立首页、独立轮播、独立导航**
- 分站可上架自有课程，也可分销主站课程
- 分站独立结算、独立后台、独立佣金比例
- 主站统一管理讲师、订单、资金、权限、审核内容
- 适合招商、渠道代理、区域分校模式

## 🧧 分销推广裂变（社交引流）

- 二级分销，可单独设置课程是否参与分销
- 自动生成带码推广海报（小程序码 / H5 链接）
- 佣金比例后台自定义，分销员门槛可配置
- 佣金明细、提现申请、后台审核打款、分销排行榜
- 邀请好友、分享奖励，适合自媒体、讲师私域引流

## 👨‍🏫 讲师入驻模块

- 讲师自主申请入驻，后台审核资质
- 讲师独立后台：上传课程、查看订单、营收、学员评论
- 讲师分成：平台设置抽成比例，自动计算讲师收益
- 讲师主页、讲师介绍、讲师课程合集

## 📱 用户端能力（小程序 + H5+PC 分站）

- 微信授权登录、手机号登录
- 课程分类、搜索、收藏、购买、订单、学习记录
- 评论、问答、课程评价
- 个人中心：我的课程、我的会员、分销中心、佣金、卡密、优惠券
- 可视化首页拖拽装修，组件自由搭配，换主题配色

## 📊 后台统计与管理

FastAdmin 原生 RBAC 权限，多管理员角色

- 数据看板：课程销量、会员数量、订单金额、分销数据、分站数据图表
- 订单管理、退款管理、资金流水、提现审核
- 学员管理、讲师管理、分站管理
- 内容审核：课程、评论、问答审核
- 短信、微信模板消息通知（购买成功、开课提醒、佣金到账、提现通知）
- 阿里云 OSS / 七牛云存储、微信支付、支付宝支付

## 🖥️ 部署环境

- PHP7.4，MySQL5.7/8.0，Nginx
- HBuilderX 打开 UniApp 源码，编译微信小程序 + H5
- PC 分站网页由 FastAdmin 后端渲染，支持绑定多个域名
